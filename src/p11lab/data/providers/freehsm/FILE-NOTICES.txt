from the pinned FreeHSM sources below. P11Lab's own Apache-2.0 license covers
only P11Lab-original material (adapter, recipe, this notice); it does not
relicense any component listed here. Full license texts live in

  Madjlessi. Texts: /usr/share/licenses/freehsm/LICENSE (upstream LICENSE)

- NIST CAVP response files (kat/cavp/*.rsp, public domain) and the IETF
  composite test text (kat/composite/mprime_appendix_d.txt, BSD-3-Clause)
  are upstream test-vector inputs. They are not compiled into the module
  and are not shipped in this image; the boot KATs run the compiled-in
  vector set. They travel with the complete retained sources.
- Extended CAVP directory KATs are not shipped: the runtime provides no
  /opt/freehsm/share/kat/ tree, so only the compiled-in vectors execute.
- System OpenSSL: the module and tool link the Debian base libcrypto.so.3
  dynamically (libssl3t64). Its terms are covered by the base Debian
  copyright/source records.
- tpm2-tools and liboqs/oqsprovider named in the upstream NOTICE are
  optional runtime-only dependencies and are NOT installed in this image;
  TPM sealing and post-quantum extensions beyond the compiled-in set are
  unavailable.
- The dispatch generator (scripts/gen_p11_thunks.py, Apache-2.0) and the
  compiler toolchain are build-time-only inputs; they are provenance
  recorded with the build, not shipped binaries.

Development variant disclosure: this image builds PROFILE=interop and the
adapter sets the documented upstream dev-mode variables
(FHSM_INTEGRITY_ALLOW_UNSIGNED=1, FHSM_KAT_ALLOW_FAIL=1), because Debian
trixie ships no OpenSSL FIPS provider and stock initialization cannot run
there. The module self-identifies these runs as token model
FreeHSM-TESTMODE. No FIPS claim is made.

Rebuild provenance (source revisions, toolchain, configuration) is
recorded under /usr/share/p11lab/build/ of this image.
