P11Lab Haskoki runtime: third-party component notices.

This runtime ships the Haskoki module and haskoki-ctl tool built from the
pinned Haskoki source below, with statically linked OpenSSL 4.0.2 libcrypto,
the OpenSSL legacy provider module, and a Haskell dependency closure.
P11Lab's own Apache-2.0 license covers only
P11Lab-original material (adapter, recipe, provisioner, this notice); it does
not relicense any component listed here. Full license texts live in
/usr/share/licenses/haskoki/ of this image; complete corresponding sources are
a separate source-companion deliverable, not this file.

- Haskoki (Haskell PKCS#11 software token), Apache License 2.0.
  Text: /usr/share/licenses/haskoki/haskoki-LICENSE (upstream LICENSE).
  Pinned revision and archive hash are recorded in the channel lock
  (rolling.lock.json) and the build receipt. No upstream release tags
  exist, so only the rolling channel is qualified.
- OpenSSL 4.0.2 (libcrypto statically linked into the module, so no shared
  libcrypto appears in the module closure; verified at build time, plus the
  legacy provider module shipped at ossl-modules/legacy.so beside the module
  because upstream loads "legacy" at open and fails closed without it),
  Apache License 2.0. Built from the pinned upstream tarball with
  no-docs/no-tests/threads/no-shared/no-pinshared; see the lock toolchain
  record and the build receipt.
- direct-sqlite 2.3.29 (Haskell SQLite bindings plus the bundled SQLite
  3.45.0 amalgamation it compiles), BSD-3-Clause, copyright Irene Knapp.
  Text: /usr/share/licenses/haskoki/direct-sqlite-LICENSE. The SQLite
  amalgamation itself is public-domain software by the SQLite authors.
  Compiled into the module and haskoki-ctl (no system SQLite is used).
- GHC 9.10.3 boot libraries and threaded runtime (base, ghc-prim,
  ghc-internal, rts and the remaining bundled libHS closure), BSD-3-Clause
  ("GHC license"). These ship as redistributed outputs of the exact pinned
  compiler bindist retained in the source companion; deeper compiler
  bootstrap provenance is not asserted.
- hsc2hs 0.68.10 (Haskell/C binding generator), BSD-3-Clause.
  Text: /usr/share/licenses/haskoki/hsc2hs-LICENSE. Build-time code
  generation only; the generated bytes compiled into the module derive
  from Haskoki's own .hsc sources.
- libffi 3.4.8 (foreign-function-interface runtime), MIT License.
  Text: /usr/share/licenses/haskoki/libffi8-copyright (Debian copyright
  file from the pinned libffi8 .deb). Vendored as libffi.so.8 with an
  ld.so.conf entry because the base image ships no libffi; system
  libgmp.so.10 resolves from the Debian base, whose terms are covered by
  the base Debian copyright/source records.
- The cabal-install binary bindist, C toolchain, Perl and other build
  inputs are build-time-only; they are provenance recorded with the build,
  not shipped binaries. The GHC bindist likewise stays out of the image
  except for its boot libraries and runtime redistributed beside the
  module (see above).

Rebuild provenance (source revisions, toolchain, configuration) is
recorded under /usr/share/p11lab/build/ of this image.
