SEMANTIC ADDITION, separate from runtime provisioning: C_GetMechanismList and
C_GetMechanismInfo replace upstream CKR_FUNCTION_NOT_SUPPORTED stubs. The patch
advertises exactly 12 mechanisms, with key sizes and flags in SUPPORTED_MECHANISMS:
CKM_RSA_PKCS_KEY_PAIR_GEN, CKM_RSA_PKCS, CKM_SHA256_HMAC,
CKM_GENERIC_SECRET_KEY_GEN, CKM_EC_KEY_PAIR_GEN, CKM_ECDSA, CKM_AES_KEY_GEN,
CKM_AES_ECB, CKM_AES_CBC, CKM_AES_CBC_PAD, CKM_AES_GCM, CKM_AES_KEY_WRAP_PAD.
It adds discovery tests (count/null/short-buffer, slot, initialization, info and
invalid mechanism) plus the existing AES-GCM 24-byte key-size limitation probe.
The advertisement remains unchanged, including the AES-GCM 16..32-byte range
despite its unsupported 24-byte gap. Findings must retain native errors and
minimal reproducers; no advertised mechanism is removed to improve test results.
The provisioning helper only calls native init-token/SO-login/init-PIN operations;
it does not modify mechanisms, PKCS#11 semantics or returned native errors.
