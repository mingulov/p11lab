P11Lab opensc-pivapplet provider file notices

Original P11Lab Dockerfile, entrypoint.sh, provision.c,
PivAppletCard.java, maven.json, fetch-jar.py, runtime-debs.txt and
patches/0001-ykpiv-short-apdu-chunks.patch: Apache-2.0, root
LICENSE. These separate orchestration modules do not relicense
OpenSC, PivApplet, yubico-piv-tool, jcardsim, vsmartcard, OpenJDK
or the Debian closure. No reference script text, credentials or
initialized card data is copied: the VSmartCard launcher is a
clean-room reimplementation (the reference workspace ships its own
wrapper with unclear authorship; no reference text is reused
here). The pkcs11-check-ws reference lane (docker/pivapplet)
informed only the pcscd/vpcd/JVM topology and the
generate+selfsign+import provisioning shape; this recipe
re-derives sources, pins, supervision and the credential model,
provisions caller PINs on stdin pipes where the reference passes
them on argv, and asserts every provisioning stage's exact native
success markers plus certificate file bounds where the reference
stops at a card listing. No simulated PKCS#11 calls and no silent
behavior changes exist.

at 5cb14a9e8d16e92fbad73dcad86a219a9210554f (11 commits after

LICENSE file: every source carries the MPL-2.0 per-file header
("This Source Code Form is subject to the terms of the Mozilla
Public License, v. 2.0", copyright Alex Wilson). The 13 applet
sources are preprocessed with the repo-bundled JPP jar at the

yubico-piv-tool (frozen provisioning CLI plus libykpiv, shared
across both OpenSC channels):
https://github.com/Yubico/yubico-piv-tool.git tag
yubico-piv-tool-2.7.3 at ed1cd7862d39a92502c0476f53dfcf93f195007a.
COPYING is the BSD 2-clause text. Built with cmake Release plus
make -j2; only the CLI and libykpiv ship. One P11Lab-authored
patch applies (Apache-2.0, SPDX header in the patch):
patches/0001-ykpiv-short-apdu-chunks.patch caps chained command
blocks at 254 data bytes so T=1 case-4S blocks never exceed the
emulator's 260-byte short-APDU ceiling; it is a host-transport
compatibility fix (ISO 7816 chaining permits any block split),
not a provisioning extension and not a PIV, PKCS#11 or
simulation semantic change. The emulator keeps its exact native
behavior, including SW 6F00 on 261-byte short APDUs, which stays
a documented unqualified surface. A declared patch that fails to
apply fails the build.

Daemon and JVM closure ships as exact extracted Debian package
bytes, not rebuilt sources: 7 whole packages (pcscd,
libpcsclite1 plus the proven link closure, plus the whole
openjdk-21-jre-headless tree), audited with ldd receipts and a
native removal proof. Whole-package /usr/share/doc copyright
files ship inside the image, plus the JRE's own per-module
legal/ texts. The JRE is OpenJDK 21.0.12.1, licensed GPL-2.0-only
with the Classpath exception (plus BSD/MIT/LGPL third-party
stanzas in its Debian copyright). liblcms2, libjpeg, libnss3,
libnspr4, ca-certificates(-java), java-common and the openssl CLI
are installed in the builder to satisfy dependencies but never
extracted: the JVM/card stack was proven green without every one
of them. libccid (USB driver bundles) and the polkitd/dbus
daemons are likewise installed but never extracted: nothing
links them, and no USB driver may be visible to pcscd. The
p11-kit PKCS#11 build header has a permissive unrestricted-copy
notice and the libpcsclite headers ship under their package
copyright; both headers' notices are retained. libp11-kit itself
is not linked.
